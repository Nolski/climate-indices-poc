What the file should look like

A plain text file with one line per day and six values on each line, separated by spaces, tabs or commas:

year, month, day, rainfall (mm), maximum temperature (°C), minimum temperature (°C)

1936  1  1    0.0   23.7   18.4
1936  1  2    1.5   24.1   17.9
1936  1  3  -99.9   25.0   18.2
1936  1  4    0.0  -99.9  -99.9
1936  1  5   12.2   22.8   17.1

Every day needs a line, in date order: write -99.9 where a value is missing. A header line is ignored. This is the same layout used by RClimDex and Climpact station files.

Station details

Used to label charts and downloaded files. If left empty, the file name is used.

Latitude tells the tool which hemisphere the station is in, which changes how seasonal indices such as growing season length are calculated. Use negative numbers for south and for west.

Base period

The base period is the span of years that defines what is normal for this station. Percentile indices, such as warm days (TX90p), compare every day with it. Choose 30 years with good data; 1971 to 2000 is the default.

Your data stays in memory on the server for 60 minutes and is never written to disk.

2 Quality control

Missing days in each year

One column per year, one row per variable. Darker cells have more missing days; taller cells are years over the limit used for annual indices.

Show the years with missing days as a table

Checks

Open a check to see the records it flagged. Nothing is removed or changed: flagged values are still used unless you correct the file and load it again.

Change the thresholds and run the checks again

The checks compare each day with these limits. Change a limit if it does not suit your climate, for example a higher rainfall limit for a cyclone-prone station. The data is not sent again.

To check again with a different base period or location, go back to step 1, change the values and choose "Apply changes". The file does not need to be chosen again.

Daily values

Plot every day of the record for one variable, with flagged values marked. The daily data is only downloaded when you ask for it.

Drag across the chart to zoom into a period; double-click to return to the whole record. With the keyboard: focus the chart and use the left and right arrow keys to read values, and the buttons above to zoom.

About this tool

This is a small working model that explores what a modern replacement for the Climpact workflow could look like: load a station file, check its quality, calculate climate indices with the open-source xclim library, and download the results.

It is built for slow and unstable connections. The whole page is well under 150 KB when compressed, loads nothing from other websites, repeats a request by itself when the connection drops, and tells you what it is doing while it waits.

Index values are compared with the original R tool for the sample station. The proof of concept covers station data and a selection of indices; it is not a finished product and its results should be checked before use in a published report.
